# Student Performance Analyzer

A beginner-friendly Python project that analyzes a student's performance across multiple subjects.

## Features

- Takes marks for five subjects
- Calculates total marks
- Calculates average marks
- Finds the highest mark
- Finds the lowest mark
- Identifies the highest-scoring subject
- Identifies the lowest-scoring subject
- Calculates the grade
- Determines the pass/fail result

## Subjects

- Bangla
- English
- Math
- Physics
- Chemistry

## Concepts Used

- Python Lists
- For Loops
- User Input
- Conditional Statements
- `sum()`
- `len()`
- `max()`
- `min()`
- List Indexing

## Technology

- Python

## How It Works

The program takes marks for each subject and analyzes the student's performance. It calculates the total and average marks, identifies the highest and lowest scores, determines the corresponding subjects, and displays the grade and result.
